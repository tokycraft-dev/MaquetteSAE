# Analyse des besoins SAÉ (2026-2027)  

## Exigences  

**\- Exigences fonctionnelles**  
 - Accéder aux logs  
 - S’inscrire  
 - Gérer les inscrits  
 - Modifier son profil/login  
 - Se désinscrire  
 - Accéder aux défis  
 - Suspendre un défi en cours  
 - Sauvegarder la progression  

**\- Exigences organisationnelles**  
 - Interface différentes pour les 4 catégorie d’utilisateurs (Admin Web, Admin Système, Inscrit et Visiteur)  
 - Accès aux défis réservé aux inscrits  

**\- Exigences techniques**  
 - Serveur web en PHP  
 - Système de base de données en MySQL (ou autre SBD)  
 - Installation sur une RPI  
 - Compte github ou gitlab pour la mise en commun
